# MesterKereső alapok – Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Működő Django-alap a MesterKereső 1. sprintjéhez: közös projekt, adatmodell, regisztráció és szerepkör-alapú bejelentkezés (Trello "Kriszti TODO", 19 óra).

**Architecture:** Egy Django-projekt (`config`) két appal: `accounts` (User, MasterProfile, regisztráció, belépés, jogosultság) és `listings` (Category, Ad, AdImage, Application, ServiceListing). Szerver oldali sablonok, mobil-first, szándékosan csupasz HTML (Filip dizájnja később cseréli).

**Tech Stack:** Python 3.12, Django ~=5.2, Pillow, dj-database-url, psycopg[binary]; SQLite helyben, PostgreSQL élesben.

**Spec:** `docs/superpowers/specs/2026-11-25-alapok-design.md`

**Munkakönyvtár:** a `Umbra-tech04/FixMyHome` GitHub-repó klónja (`/home/claude/FixMyHome`). A spec és ez a terv a repóba kerül (`docs/superpowers/...`) az 1. feladatban.

**Eltérés a spectől:** az `accounts.User` teljes mezőkészlete (e-mail belépés, név, telefon, szerep) már az 1. feladatban elkészül, mert az `AUTH_USER_MODEL` és a `USERNAME_FIELD` az első migráció után nem cserélhető fájdalommentesen.

## Global Constraints

- Python 3.12, Django 5 (`Django~=5.2`), függőségek `requirements.txt`-ben, venv (`.venv`).
- `DATABASE_URL` környezeti változó választ adatbázist; alapértelmezés `sqlite:///db.sqlite3`; nincs PostgreSQL-specifikus funkció.
- `LANGUAGE_CODE = "hu"`, `TIME_ZONE = "Europe/Belgrade"`; a felület magyar, a kód és azonosítók angolok.
- Szerepkörök: `USER`, `MASTER`, `SUPPORT`, `COMPANY`; regisztrációnál csak `USER` vagy `MASTER` választható.
- Hirdetésállapotok: `OPEN` → `IN_PROGRESS` → `DONE` (megjelenített nevek: Nyitott, Folyamatban, Lezárva).
- Egy e-mail-címmel egy fiók; a jelszó Django-hash-sel tárolódik.
- Appok: `accounts`, `listings`; a `moderation` appot Adrian hozza létre.
- Git: `main` stabil, minden feladat külön ág (`feature/kriszti-<feladat>`), kis PR, squash merge. Az 1. feladat bootstrap commitja közvetlenül `main`-re mehet.
- Tesztfuttatás: `python manage.py test`; a hibaüzenetek magyarul.
- Nincs kinézet, PWA, térkép, fizetés, hosting ebben a tervben.

## Review Focus

Egy használó valószínűleg ezeken botlik meg, a spec nem mondja ki őket:

1. Ugyanaz az e-mail eltérő kis/nagybetűvel (`Anna@Example.com` / `anna@example.com`) egy fiók legyen, és a belépés is működjön vele. (Task 1, 3, 4)
2. Regisztrációs POST-ban kézzel átírt `role=support` vagy `role=company` ne adjon jogosultságot, az űrlap utasítsa el. (Task 3)
3. Mesterregisztráció hiányzó szakmával/területtel/elérhetőséggel ne hagyjon félkész User-t profil nélkül. (Task 3)
4. A belépés utáni `?next=https://masik-oldal.example` ne irányítson át külső oldalra. (Task 4)
5. Használatban lévő kategória törlése ne törölje a hirdetéseket és mester-profilokat (`PROTECT`). (Task 2)
